MySchool Portal - Cloud Functions Deployment Guide

This guide explains how to deploy the new Node.js (Firebase Cloud Functions) backend. This completely replaces Google Apps Script.

Prerequisite: Node.js & Firebase CLI
You must have Node.js installed on your computer. You must also install the Firebase Command Line Tools by running npm install -g firebase-tools in your terminal.

1 Initialize Firebase in Your Project

  1. Open your terminal (Command Prompt or PowerShell).
  2. Navigate to your new folder: cd "Myschool Portal Cloud Version"
  3. Log in to Firebase via terminal: 
    firebase login
    (This will open a browser window for you to log in with your Google account).
  4. Initialize the project: 
    firebase init functions
  5. When prompted:
    • Select Use an existing project and choose your Firebase project.
    • What language? Select JavaScript.
    • Use ESLint? Select No.
    • Do you want to install dependencies with npm now? Select Yes.

2 Overwrite with Template Files

  1. During initialization, Firebase may have created a default index.js and package.json inside your functions/ folder.
  2. Ensure the index.js file inside functions/ contains the Express API code that was provided in this template. (If it asks to overwrite during setup, do NOT overwrite the custom one).
  3. Ensure all your necessary dependencies are installed by running: 
    cd functions
npm install express cors uuid firebase-admin firebase-functions

3 Deploy the Cloud Function (Backend)

Unlike Google Apps Script, you don't need to manually configure Private Keys or Service Accounts in Script Properties. Firebase Cloud Functions automatically authenticate themselves with your Firestore Database!
  1. Make sure you are in the root folder (Myschool Portal Cloud Version).
  2. Deploy the function to Firebase: 
    firebase deploy --only functions
  3. Wait for the deployment to finish. The terminal will output a Function URL. It will look something like this:
    https://us-central1-yourprojectname.cloudfunctions.net/api
  4. Copy this URL.

4 Connect the Frontend

  1. Open the api.js file located in the root of your frontend files.
  2. Find the SCRIPT_URL constant at the top of the file: 
    const SCRIPT_URL = "YOUR_APPS_SCRIPT_URL";
  3. Replace it with the new Cloud Function URL you copied in Step 3: 
    const SCRIPT_URL = "https://us-central1-yourprojectname.cloudfunctions.net/api";
  4. Save api.js.

5 Host the Frontend

  1. Just like the previous architecture, push all your HTML, CSS, and JS files to GitHub.
  2. Go to your repository settings and enable GitHub Pages from the main branch.
  3. Your portal is now live, running on a massively scalable Node.js backend with zero latency!
